# Security policy

ARK is experimental and can give unsafe answers. The full safety notice, in Portuguese, is in [SEGURANCA.md](SEGURANCA.md).

## Reporting

- **Unsafe answer** (the model contradicts its cited source or could cause harm): open a public issue with the "Resposta perigosa" template. These are the most valuable reports for the project.
- **Software vulnerability** (for example, something that exposes the computer to the network): do not open a public issue. Use [private vulnerability reporting](https://github.com/AndreOvigli/ark-doomsday/security/advisories/new).

ARK runs locally and only listens on 127.0.0.1. There are no supported versions yet; fixes land on `main`.
