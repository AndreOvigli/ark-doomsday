# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/). Em resumo:

- Trate todo mundo com respeito, em issues, PRs e discussões.
- Critique ideias e código, nunca pessoas.
- Sem assédio, ofensa ou exposição de dados de terceiros.
- Lembre que o assunto é segurança de gente de verdade: na dúvida, prefira a cautela e cite a fonte.

Comportamento inaceitável pode ser reportado em privado para o mantenedor pelo [aviso privado do GitHub](https://github.com/AndreOvigli/ark-doomsday/security/advisories/new) ou por mensagem no perfil [@AndreOvigli](https://github.com/AndreOvigli). O mantenedor pode remover comentários, commits ou contribuições que violem este código.
